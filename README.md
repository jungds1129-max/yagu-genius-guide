# 야구천재 공략 정리 (yagu-genius-guide)

모바일 야구 육성 게임 "야구천재"의 패치 노트, 인게임 가이드, 상점·과금, 육성 공략을 정리한 자료입니다.
공지와 인게임 가이드 원문을 옮겨 정리한 것이며, "추정", "미확인"으로 표시된 내용은 확정값이 아닙니다.
