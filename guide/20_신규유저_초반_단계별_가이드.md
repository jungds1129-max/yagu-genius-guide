# 야구천재 신규 유저 초반 가이드 (2026-10-24 기준)

게임이 처음엔 막막한데, 사실 **"라인업 채우기 → 매일 우편함 받기 → 골드 아껴 쓰기"** 세 가지만 지키면 반은 먹고 들어갑니다. 아래 순서대로 따라 하세요.

---

## 0단계. 먼저 알아둘 것 (이거 모르면 손해)

| 규칙 | 내용 |
|---|---|
| 시즌 | 월–토 6일, 매일 19경기, 30분 간격 **자동 진행**. 직접 안 눌러도 경기는 돌아감 |
| 몰수패 | **라인업 미완성 또는 샐러리캡 초과 = 매 경기 0-1 몰수패** |
| 정산 | 토요일 18:30. 이때 **연봉이 자동 차감**되고 나이 +1 |
| 보상 | 경기·순위 보상은 **우편함에서 [받기]**를 눌러야 들어옴 |

---

## 1단계. 가입 직후 (첫 30분)

1. **창단하면 골드 100,000이 바로 지급**됩니다. 28명 로스터(선발 6·중계 4·마무리 2·야수 16)가 자동 생성돼요.
2. **무료 10연 뽑기**: 창단 후 안내되는 [무료 10연 시작하기]를 누르세요. 무료권이 남은 동안 하루 1회.
3. **라인업 완성하기 (가장 중요!)** 아래 5개를 전부 채워야 합니다.
   - 야수 선발 9명
   - 벤치(후보) 5명
   - 선발 로테이션 (최대 5명, 빈 슬롯 있으면 그 차례는 몰수패)
   - 불펜: 승리조 3 + 추격조 2 + 패전조 2
   - **마무리 1명 (비면 안 됨)**
4. **샐러리캡 확인**: 동네리그는 라인업 연봉 합계 **30,000 이하**. 넘으면 몰수패. 모르겠으면 연봉 높은 선수부터 빼 보세요.
5. 저장하면 끝. 이후엔 자동으로 경기가 진행됩니다.

> 💡 라인업 프리셋 1–3번에 저장해 두면 나중에 갈아끼우기 편해요. 불러온 뒤 **각 탭에서 다시 저장**해야 반영됩니다.

---

## 2단계. 첫 주 (시범리그 → 첫 정규 시즌)

**가입하면 먼저 "시범리그"가 자동 참여됩니다.** 경기 보상과 선수 경험치는 받지만 순위 보상·승격·강등은 없어요. 연습 기간이라 생각하세요. (토/일에 가입하면 시범리그 없이 다음 주 정규리그)

### 매일 할 일 (5분 컷)
- ☑ **출석 체크** — 7일 연속이 1사이클(하루 빠지면 1일차부터). 7일 합계 골드 17,000 + 다이아 50. 출석 후 광고 보면 다이아 10 추가.
- ☑ **우편함 [전체 받기]** — 경기 골드·순위 보상이 여기로 옴. 60일 지나면 소멸.
- ☑ **연습경기** — 2시간마다 1개 충전(최대 3개). 봇 팀 10팀을 처음 이길 때마다 다이아 지급(10팀 전부 합치면 약 5,600다이아). **초반 최고 다이아 수입원**이니 매일 쓰세요.
- ☑ **광고 무료 뽑기** — 3회 충전, 쿨다운 12시간.
- ☑ **라인업 / 부상 알림 확인** (아래 주의사항 참고)

### 첫 주 체크리스트
- ☑ 몰수패 푸시가 안 오는지 확인
- ☑ 훈련·유학 슬롯 비워두지 말기 (선수 경험치가 곧 전력)
- ☑ 무료 재화(출석, 연습경기, 광고)만으로 충분히 굴러가니 **다이아 결제는 서두르지 않기**

## 3단계. 첫 몇 시즌 (동네 → 아마추어 → …)

### 한 주 루틴 (토요일 정산 전후)
| 시점 | 할 일 |
|---|---|
| 평일 저녁 | **드래프트 센터**에서 지명 방식 선택 (희망 지명 / 자동 / 미참여). **안 고르면 미참여 처리**돼요. 토요일 저녁 마감 |
| 평일 20–23시 | FA 시장 확인 (주 3명 한도, 입찰 즉시 골드 차감) |
| **토 18:30 전** | **골드 잔액 확인** (연봉 차감 대비) + **재계약 대상 확인** |
| 토 정산 후 | 우편함에서 순위·승격 보상 [받기] |

### 드래프트 (공짜 선수 1명!)
- 매주 18–22세 유망주 50명이 나옵니다. 순위가 낮은 팀부터 먼저 고르는 **역드래프트**라 하위권일수록 유리해요.
- 지명 방식을 골라야 **무료로 1명** 영입. 계약 7시즌, 보유 한도 초과해도 OK.
- **희망 지명은 최대 10명**까지 순서대로 적어두면, 앞 순위가 뺏겨도 다음 순위로 채워줍니다. 스카우트권(주 3장)으로 능력치·포텐셜을 미리 볼 수 있어요.

### 재계약 (놓치면 선수 사라짐)
- 계약이 **0시즌 남은 선수는 만료**됩니다. **1주일 안에 재계약 안 하면 다음 토요일 18:30에 자동 방출!**
- 헷갈리면 **일괄 재계약** 사용. 단, **골드가 부족하면 아무도 재계약이 안 되니** 골드부터 확인하세요.
- 같은 선수와 1년 계약만 반복하면 충성도가 떨어져 추가 비용이 붙어요. 키울 선수는 3–5년으로.
- 나이 + 계약연수 ≤ 40세. 40세가 되면 강제 만료.

### 골드 아껴 쓰기 (제일 많이 하는 실수)
1. **토요일 정산에 연봉이 자동 차감**됩니다. 골드를 0으로 만들어 쓰면 마이너스가 돼요. **마이너스가 되면 연봉 외 골드 사용이 전부 막힙니다** (골드를 벌면 자연 복구).
2. 일반 뽑기(골드)는 4·5성 확률이 0.1%/0.01%라 **효율이 매우 낮아요.** 골드는 뽑기보다 **재계약, 훈련**에 쓰세요.
3. 재계약·FA는 계약금이 따로 나갑니다 (1시즌 800% – 5시즌 15%). FA는 연봉이 높고 샐러리캡도 먹으니 신중하게.
4. 다이아는 **함부로 쓰지 말고 모아두기**. 특히 초반 즉시회복·즉시완료에 쓰는 건 아깝습니다.

### 선수 키우기 기본
- 경기에 내보내는 것만으로도 경험치가 쌓이고 (라인업 전원 EXP 5), MVP는 +15.
- **선수 잠금**을 걸어두면 실수로 방출·재료 사용하는 걸 막을 수 있어요 (무료).
- 5성 각성/특성 리롤은 비용이 크니 **초반엔 하지 마세요.**

## 몰수패·사고 방지 체크리스트 (이것만 외워도 OK)

몰수패가 나는 경우:
- ✘ 야수 선발 9명 미만
- ✘ 벤치 5명 미만
- ✘ 로테이션 0명, 또는 **빈 슬롯 차례**
- ✘ 마무리 없음
- ✘ **라인업 연봉이 샐러리캡 초과**

자주 놓치는 함정:
- ⚠ **부상 알림이 오면 벤치 인원부터 확인.** 후보가 선발로 올라가면 벤치가 5명 아래가 돼서 다음 경기 몰수패. 부상 회복 후에도 자동 복귀 안 함.
- ⚠ **선발투수는 한 번 등판하면 4경기 쉬어야** 합니다. 휴식이 부족한 투수는 슬롯 이동 후 저장해야 해요.
- ⚠ 라인업 선수를 **방출/은퇴/보관**하면 자동으로 빠집니다. 빈 곳을 꼭 채울 것.
- ⚠ 경기 절반 이상 몰수패 → **동네리그로 강등**. 전부 몰수패면 강등 + 다음 시즌 자동 불참.
- ⚠ 라인업 미설정 상태로 3일 이상 접속 안 하면 시즌 참가가 **자동 중단**됩니다 (로그인하면 다음 시즌부터 복귀).
- ⚠ **토 18:25–18:35, 일 23:45–월 00:10 정산 시간**엔 뽑기·방출·훈련·FA·라인업 변경이 불가. 이 시간 피해서 작업하세요.
- ⚠ 35세 이상 선수는 **정산 때마다 모든 능력치 -3**. 베테랑 의존은 짧게, 세대교체는 미리.

## 한눈에 보는 순서 요약

1. 창단 → 무료 10연 뽑기
2. 라인업(야수 9+벤치 5+로테이션+불펜+**마무리**) 완성, 샐러리캡 확인 → 저장
3. 매일: 출석 / 우편함 받기 / 연습경기 / 광고 무료뽑기
4. 매주: 드래프트 지명 방식 선택 / 재계약 확인 / 토요일 전 골드 확인
5. 부상 알림 오면 벤치 5명 확인
6. 골드는 쟁여두고, 다이아는 아끼기
